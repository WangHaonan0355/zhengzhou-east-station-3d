# 郑州东站 · 3D 互动模型

用 Three.js 从零参数化建模的郑州东站 3D 互动模型，整个项目就是**一个 HTML 文件**，浏览器打开即用，无需安装任何东西。

## 看什么

- 高铁站房主体结构：雨棚、轨道、站台、站名标识
- 鼠标拖拽旋转 / 滚轮缩放，360° 自由观察
- 纯代码建模，没有加载任何外部模型文件

## 在线体验

GitHub Pages：启用后见仓库首页 About 区域的链接（`index.html` 即入口）

## 技术要点

- **参数化建模**：站房、轨道、立柱等全部由代码按几何规则生成，改一个参数就能调整比例
- **Three.js 单文件集成**：所有逻辑、材质、灯光、相机控制收敛在一个 HTML 内
- **性能取舍**：控制面数、合并几何体，保证普通笔记本浏览器流畅运行

## 本地运行

直接双击 `index.html`，或托管到任意静态服务器。
